What it never does

Five switches, not five settings: turn one on and it shows the part of Flit that keeps the promise.

It never asks for an account.

No email, no sign-in, no cloud: two devices, two keys, and nothing else on the wire.

It never gives a broken file its name.

The receiver hashes sha256 while it writes, then installs. A mismatch leaves the .part in place and says so.

It never trusts a key it has not pinned.

First contact pins the fingerprint. If a device comes back with a different key the send is refused, and there is no bypass to click.

It never repeats what already arrived.

A dropped send asks the receiver for the range it already holds, so only the missing bytes cross the wire.

It never needs the internet.

Discovery is a multicast announcement on the local network and the transfer is one TLS connection between the two devices. Nothing is relayed; unplug the wide area link and the send still works.

Before you send

Do I need an account?

No. There is no account, no sign-in and no server in the middle. Two devices that can see each other on the network are enough.

Where do my files go?

Straight to the other device, over TLS 1.3, and nowhere else. There is no relay and no copy kept for later, because there is no server to keep it.

Can it move a whole folder?

Yes. Pick the folder and Flit lists its files, hashes them before the manifest, and sends them as one batch with one progress lane and one cancel.

What happens if the Wi-Fi drops?

The send picks up where it stopped. The receiver keeps the partial file and reports the byte range it has, so the next attempt carries only the rest.

How do I know it is the right device?

Every device has a key and a fingerprint, and the same four words and four emoji sit on both screens. The key is pinned the first time, and a device that comes back with a different one is refused.

Does it work across the internet?

No, on purpose. V1 is for devices on the same network: there is no relay, no hole punching, and no rented server in the path. A typed address can cross a subnet; discovery never does.

Is there an Android build?

Not yet. Windows and Linux are the first targets and both build today; Android is next. Nothing is downloadable until the installer is done.

Is it free?

Yes. Flit is free software under MIT OR Apache-2.0, and the source is on GitHub. No paid tier, no account to cancel, no usage to meter.

Nothing to download yet.

Flit is pre-alpha. The protocol, the engine and the desktop shell are built and tested; the installer is not. When there is a build it will be a release on GitHub — no email, no waitlist, no counter on this page.
